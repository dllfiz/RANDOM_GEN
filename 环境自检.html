换环境时怎么把存档带走

  1. 在原环境打开 index.html → 左侧「仓库」→ 点 ↓ 备份全部存档，得到一个 randgen-存档-*.json。
  2. 把这个 json 和整个项目文件夹一起复制到新环境（U 盘 / 网盘 / 压缩包都行）。
  3. 在新环境打开 index.html → 点 ↑ 恢复存档 → 选这个 json。历史、收藏、自建角色卡、解锁状态全部回来。
  4. 角色工坊（role-studio/index.html）共用同一份存档，无需再导一次。

存档保存在浏览器里，不在项目文件夹里。所以「复制项目文件夹」本身不会带走存档，必须走上面第 1 步导出。
换浏览器也算换环境：Chrome 和 Edge 各存各的，互不通用。

两种打开方式的区别

本地文件
双击 index.html		 最省事，直接双击即可。
地址栏是 file:///…。功能完整可用。
本地服务
python -m http.server		 需要装 Python，多一步。
地址栏是 http://localhost:…。
功能一样，但存档和上面那格互相看不见。

两种方式都能正常读写存档、导出、复制。区别只在「存档放在哪个来源下」。建议固定用一种，别来回切。
