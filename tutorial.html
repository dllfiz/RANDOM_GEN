1. 这是什么 / 怎么打开

RANDOM GEN 是在浏览器里本地运行的二次元 AI 绘图提示词生成器。它根据你选的角色、场景、标签等，拼出 Positive / Negative 英文提示词，也可提交到本机 ComfyUI 直接出图。

  • 不上传数据到远程服务器（大模型优化除外，需你自己填 API）。
  • 清水内容默认可用；成人内容需点顶栏「夜灯」确认后解锁。
  • 纯前端即可双击使用；连 Comfy / 自动写回存档时建议用启动脚本。

两种打开方式

方式怎么做适合
双击 index.html
或 打开生成器.bat		 有浏览器即可，地址栏是 file://… 只生成提示词、不连 Comfy
双击 启动生成器.bat 起本地服务（默认端口 8777），自动开浏览器
地址形如 http://localhost:8777/index.html		 提交 Comfy、存档自动同步、大模型配置
必须整包使用。只复制一个 index.html 会缺 assets/ 脚本，功能几乎全废。换电脑请拷整个项目文件夹。

3. 顶栏：底模、夜灯、新建角色

底模下拉

决定画质词 / 负面词写法（不是 Comfy 里实际加载哪个 .safetensors 文件的唯一来源，但部分选项会带推荐 checkpoint 名）。

  • 系列风格：Animagine XL、Illustrious（光辉）、Pony Diffusion、NoobAI-XL
  • 具体 checkpoint 选项：如 waiIllustrious v140/v160/v170、Illustrious-XL v1.1、cocoStyle NoobAI 等

切换底模后，已生成的提示词会按新底模的质量词规则重写一遍。

温馨提示 · 角色卡自动切底模： 若自定义 / 预设角色卡写了推荐底模（preferredCkpt / preferredModel）， 在左侧选中该卡时会同时：
  • 下方 Comfy「底模 Checkpoint」自动选到对应文件（本机列表里有的话）
  • 顶栏「底模」下拉也会自动切到匹配的质量词方案（例如双叶 → waiIllustrious v140）
这样提示词写法与实际出图 checkpoint 不容易各用各的。无推荐字段的卡不会强行改你当前底模。

夜灯（清水 / 成人）

顶栏灯泡按钮：

  • 清水：默认。不出现成人标签、体位、题材包等。
  • 夜灯点亮：首次需确认；解锁后左侧出现「标签」分区（体位类别、题材包、内容标签、动作自选），生成走 NSFW 逻辑与互斥过滤。

解锁状态会记在浏览器本地（randgen_unlock_nsfw）。

其他顶栏入口

  • 说明 → 本页
  • 工坊 → 提示词工坊
  • ＋ → 新建自定义角色卡（弹窗编辑外貌 / 默认服饰等）

4. 左侧 · 角色来源

决定「画谁」。可以不选（纯随机外貌），也可以指定一张或多张角色卡。

  • 选择角色：打开角色面板，按作品 IP、性别、关键词搜索；点选卡加入「已选」。
  • 随机抽卡：每次生成从卡池里按筛选条件随机抽，数量跟出场人数相关。
  • 预设 / 自定义：内置大量二次元角色；也可新建卡（含 LoRA 名、强度、推荐底模等）。
  • 清空选择：取消所有已选卡。
单卡注意：只选 1 张角色卡时，程序用「预设补全」路径拼提示词。场景场所等已与配置明细对齐；生成后请以右侧 POSITIVE 全文为准确认是否含地点等词。

部分角色（如「双叶」）会在提示词开头固定触发词，并尽量自动带上角色 LoRA 与推荐底模。

5. 左侧 · 基本设定

  • 角色性别：随机 / 女 / 男 / 扶她。已选角色卡时会按卡的性别对齐，并提示。
  • 出场构成（夜灯后）：男人数、女人数分开选，用于多人 NSFW 场景人数与标签一致性。
  • 清水模式通常按单人逻辑处理，人数选择以界面实际显示为准。

6. 左侧 · 画师

可选一位或多位画师风格标签（最多约 6 位），选中后全部追加进提示词。可按分类筛选、搜索、「选当前整组」。

不选则按画风预设或随机画风填充。

7. 左侧 · 场景自选

每一项默认是「🎲 随机」；点选某个 chip 即锁定该项，再点一次取消锁定。

项作用
场所地点背景，如地下车库、海边沙滩、春日樱花大道等。锁定后应出现在 POSITIVE 的英文地点描述中。
时间光线光照与时段，如书桌灯、黄昏逆光、篝火等。
氛围空气感、气味、心理氛围等描述的英文对应。
构图镜头全身、特写、鸟瞰、过肩等。
行为姿态清水向姿态/行为倾向（偏叙事；英文 tag 能力弱于场所光线）。
情绪基调情绪色彩，多用于中文情境/明细。
眼睛特效特殊瞳效等（若词库有对应英文会写入）。

✕ 清空场景自选：全部恢复随机。

锁定场景后请重新点「生成提示词」。只看「本次配置明细」不够，务必核对 POSITIVE 里是否出现对应英文（如 underground parking garage、cherry blossom avenue）。

8. 左侧 · 体型自选 · 服饰

体型自选（人生组图）

在「衣着」上方。用于同一角色从小画到大的系列图，不选则随机身材。

档位说明
Q版超级变形、头身比极小
幼小比例 / 儿童比例偏矮、头身比偏大
少年少女青少年比例
青年标准 / 成人匀称成年正常体型
成人丰满 / 成人高大 / 大体型 / 健壮肌肉成熟或偏大体型
  • 点选 = 锁定该档，英文体型 tag 写入 POSITIVE
  • 再点同一档：权重 ★（约 1.2）→ ★★（约 1.5）→ 取消
  • 「✕ 清空体型锁定」恢复随机
组图技巧：固定同一角色卡，只切换体型档依次生成，即可得到「Q版→幼小→少年→成人…」一组成长向画面。

服饰

  • 衣着状态：默认 / 正常着衣 / 半脱 / 露胸 / 全裸等（全裸、半脱等主要在夜灯 NSFW 下完整生效）。
  • 服装：保留角色原设、随机换装、或指定成套服饰（兔女郎、JK、女仆等）。

预设角色卡通常把「外貌 core」与「原设服装 outfit」分开，换装/全裸时可以剥掉或替换服装段。

9. 左侧 · NSFW 标签区 需夜灯

以下整区仅在顶栏夜灯开启后显示。请仅在合法、自愿、成年人的前提下使用。

9.1 体位类别

下拉限制本次体位池的大类，避免完全随机飘到不想要的方向：

  • 🎲 随机体位（不限制）
  • 正面位（面对面）
  • 后入位（背后）
  • 骑乘位（女上）
  • 口交位（舔吮）

引擎会按物理状态（束缚、口塞、平胸等）继续过滤「画不出来」的组合。

9.2 题材包

约 30 类主题。点击 = 勾选必出；再点可在权重 ★（约 1.2）/ ★★（约 1.5）间循环。整组英文 tag 注入提示词。

部分重口 / 特殊题材默认不参与「随机补全」，只有你显式勾选才会生效。

9.3 内容标签

大量细项标签（界面提示约数百项），按大组折叠。用法与题材包类似：

  • 点一下：勾选，该标签英文必出
  • 再点：提高权重 ★ / ★★
  • 再点：取消

工具按钮：全选 / 清空 / 反选。

标签方案：给当前勾选（含权重）起名保存，之后一键载入；可删除方案。

引擎会根据人数、性别、是否单人、是否勾选非人等做互斥过滤（例如口球与口交不同时成立、单人不会抽需要第二人的句子等）。

9.4 动作自选（法典库）

搜索内置动作法典，点选后该动作的整组加权 tag 必出。与当前出场人数不符的会自动跳过；百合等前提会做指代剥离。

已选动作显示在下方 chips，可逐个取消或「清空已选」。

9.5 NSFW 生成时引擎还会自动做的事

  • 道具 / 束缚 / 口部器具等按标签与状态抽取，并更新「物理事实」
  • 体位、动作、台词、体液等在事实约束下抽取，减少矛盾组合
  • 单人 / 双人 / 群交、女女、匿名男等分支使用不同词池
  • 负面词在全裸与着衣时策略不同（着衣时不会用「脱掉衣服」类负面硬怼服装）

10. 右侧 · 中文 → 提示词

  • 文本框默认较大，可用右下角拖拽横向 + 纵向继续放大。
  • 仅中文：本地规则转换；若启用大模型则走 API。
  • 仅参考图：须启用大模型；分析服装（上装/下装/袜/鞋/配色）、眼神表情、姿势动作、背景、光影。
  • 图 + 文：以图为主，中文作辅助需求。
  • 转成提示词 / 大模型再优化 / 同步到当前：转换结果写入 Positive / Negative。

角色触发词始终以左侧「角色来源」为准并置顶，不因中文名覆盖角色卡。

11. 右侧 · 提示词结果与导出

  • POSITIVE / NEGATIVE：可直接编辑，再复制或提交 Comfy。
  • token 估算：按 CLIP 大致估算；常见上限约 225。超出部分在真实出图时可能被静默截断。
  • 裁到 225：勾选后自动裁掉低价值词以贴近上限。
  • 复制 / 复制负面词
  • 收藏：写入仓库收藏夹
  • 导出 MD / CSV / PNG：Markdown 代码块、表格行、或把提示词做成图片卡片
  • 本次配置明细：展开后可看角色与场景各字段；点 🎲 可只重掷某一项再重拼提示词
明细与 POSITIVE 在修过单卡路径后应对齐。若仍不一致，以 POSITIVE 为准并重新生成。

12. 右侧 · 仓库与存档

  • 历史：每次生成可记入历史列表，可点回载入。
  • 收藏：手动收藏的条目。
  • 导出 JSON / TXT：导出当前仓库内容。
  • 清空：清空列表（慎用）。
  • ↓ 备份全部存档：历史 + 收藏 + 自建角色卡 + 解锁状态等，换机用。
  • ↑ 恢复存档：选回备份的 JSON。
  • 💾 写回存档文件：生成 store.js，拖进项目 存档/ 覆盖，即可随文件夹搬家（双击 file 模式尤其有用）。

file:// 与 http://localhost 的存档互不通用（浏览器按来源隔离）。换打开方式或换浏览器时，用备份/写回文件迁移。

13. 右侧 · 生成与 ComfyUI

生成

  • 🎲 生成提示词：按当前全部设定生成一组。
  • ⚡ 批量生成 10 组：连续生成多组（便于挑）。
  • 随机种子 seed：填同一数字 + 相同配置可复现同一套提示词；留空则每次随机。
  • 常驻负面词：每次自动追加到 Negative 末尾。

ComfyUI 一键出图

需要：本机 ComfyUI 已运行，且本页用 启动生成器.bat（http 模式）打开。

  • 基础配置（可多选）：勾选 comfy-templates/ 下多个模板；一次提交会按「提示词组 × 模板」全部入队。改模板文件后请重启生成器服务。
  • ComfyUI 地址：默认 http://127.0.0.1:8188。
  • 底模 Checkpoint / 角色 LoRA / 强度：可从本机 Comfy 扫描列表；选角色卡时常自动填入卡上的 LoRA 与强度。
  • 当前界面为单个角色 LoRA + 一个强度（模型与 CLIP 强度写入时相同）。多 LoRA 节点需在模板里预置，不能在界面随意加减行。
  • 出图编号前缀、批量张数、提交范围、种子策略等按面板说明设置。
  • ▶ 提交到 ComfyUI 并开始画：把当前提示词填进模板并入队。
  • ↓ 下载工作流 JSON：不直接提交，下载后在 Comfy 里手动 Load。
本程序不直连 Automatic1111 / Forge 等 SD WebUI，那些工具请复制提示词手动粘贴。

15. 常见问题与注意

场景选了却不出对应词？

请确认：已重新点生成；看的是 POSITIVE 不是只看明细；已使用含「场景锁定修复」的版本；token 未严重超限被裁光。单卡路径已修复为尊重场所/光线/构图/氛围及明细中的体位、体液、道具等。

为什么明细和提示词曾经不一致？

只选一张角色卡时会走预设补全路径，旧版会重抽背景。新版会优先用场景自选与 makeScene 结果，并强制把缺失的英文地点等补回 POSITIVE。

提示词很长但图里没体现？

模型侧 CLIP 有效长度有限（约 225 token）；角色与动作权重常压过背景。可减少标签、给地点加权重，或拆成多次生成。

双击 HTML 无法提交 Comfy？

file 协议下无法按设计请求本机 API。请用 启动生成器.bat。

换电脑历史没了？

用仓库「备份全部存档」或「写回存档文件」，把整个项目文件夹一起带走；新环境打开后按说明恢复。

推荐最短流程

  1. 启动生成器.bat
  2. （可选）需要成人内容 → 点夜灯
  3. 选角色卡或保持随机
  4. 锁定场所等场景项
  5. 需要时勾选 NSFW 标签 / 题材 / 动作
  6. 生成提示词 → 检查 POSITIVE
  7. 配置 Comfy 地址与模板 → 提交出图

16. 多分辨率模板与多选入队

项目 comfy-templates/ 内除 base.json / simple.json 外，还提供竖屏、横屏、方图多种分辨率工作流（如 1024×1536、832×1216、1536×1024、1024×1024 等）。

  • 在「生成」区以勾选列表选择一个或多个模板。
  • 提交时每个模板会单独加载并分别入队；不再只生效「最后一个」。
  • 例：1 组提示词 × 3 模板 = 3 个任务；批量 10 组 × 2 模板 = 20 个任务。
  • 含手部 Detailer 的模板在「每组多张」时会自动拆成多个 batch=1 任务，避免 Impact Pack 报错。

17. 参考图识图（中文区）

  • 上传区域在「中文 → 提示词」卡片内，圆角虚线框，支持预览与清除。
  • 原图建议不超过 20MB（上传后会自动压缩到约 1536 边长再送大模型）；走 OpenAI 兼容的多模态 image_url 格式。
  • 模型需支持视觉（如部分多模态接口）；纯文本模型会失败，请换模型名。
  • 输出仍为英文 danbooru 风格标签，角色 core 置顶。
